# gvs_arh — MVP

Сайт для отметок жителей Архангельска о наличии горячей воды.

## Что уже есть

- Яндекс Карта.
- Нажатие на территории/районы.
- Статус «вода есть / воды нет».
- Счётчики голосов.
- Комментарии.
- Адаптивная версия для телефона.
- Демо-режим через localStorage.
- Заготовка Supabase для общей базы.

## Запуск

1. Создайте API-ключ Яндекс Карт.
2. Откройте `index.html`.
3. Замените `YOUR_YANDEX_API_KEY` на свой ключ.
4. Откройте сайт через локальный сервер или GitHub Pages.

## Общая база

Если хотите, чтобы комментарии и голоса были видны всем:

1. Создайте проект Supabase.
2. Откройте SQL Editor.
3. Выполните `supabase.sql`.
4. Получите URL проекта и publishable/anon key.
5. В `app.js` заполните `CONFIG`.

Для продакшена нужно отдельно реализовать запись/чтение из Supabase вместо localStorage, антиспам и ограничение частоты голосований.

## Важно про районы

Координаты в `app.js` сейчас демонстрационные, а не официальные границы районов. Перед публикацией их нужно заменить на точный GeoJSON с выбранными вами территориями.

Яндекс JS API официально поддерживает полигоны, GeoJSON и события клика по геообъектам.


## Стартовый вид карты

При открытии сайта карта автоматически центрируется на Архангельске (примерно 64.5393, 40.5433) и показывает город крупным планом. Точные границы районов пока демонстрационные и требуют замены на официальный GeoJSON.
