# gvs_arh

MVP сайта для отметок жителей Архангельска о горячей воде.

В этой версии используется Leaflet + OpenStreetMap, поэтому API-ключ для карты не нужен.

При открытии сайт сразу показывает Архангельск.

Важно: границы районов в `app.js` демонстрационные. Перед полноценным запуском их нужно заменить на точные GeoJSON-границы выбранных территорий.

Голоса и комментарии пока сохраняются в localStorage конкретного браузера. Для общей базы на всех устройствах подключим Supabase следующим этапом.
