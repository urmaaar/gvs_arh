# gvs_arh v2

Полностью обновлённый интерфейс:
- карта Архангельска сразу при входе;
- 9 территориальных округов;
- аккуратные подписи округов;
- зелёный/красный/серый статус;
- голосование;
- комментарии;
- адаптация под телефон;
- карта на Carto + OpenStreetMap, без API-ключа Яндекса.

Важно: координаты полигонов сейчас являются визуальной рабочей разметкой, а не юридически точной кадастровой границей. Официальные материалы администрации Архангельска подтверждают деление города на 9 территориальных округов: Северный, Соломбальский, Маймаксанский, Октябрьский, Ломоносовский, Майская Горка, Варавино-Фактория, Исакогорский и Цигломенский.

Следующий этап — заменить рабочую разметку на точный GeoJSON и подключить Supabase, чтобы голоса и комментарии были общими для всех пользователей.
