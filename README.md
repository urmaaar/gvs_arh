# gvs_arh v3

Что добавлено:
- голоса и комментарии через Supabase, если заполнены SUPABASE_URL и SUPABASE_ANON_KEY;
- большинство голосов определяет статус и цвет округа;
- один браузер может изменить свой голос, а не накручивать его бесконечно;
- кэш точных границ округов в localStorage: после первого успешного получения карта загружается намного быстрее;
- `arh_gvs` в правом верхнем углу — кнопка обновления сайта;
- если Supabase не подключён, сайт временно работает в локальном режиме.

## Подключение общей базы

1. Создайте бесплатный проект Supabase.
2. Откройте SQL Editor и выполните `supabase.sql`.
3. В настройках проекта найдите Project URL и Publishable/anon key.
4. В `app.js` заполните:
   SUPABASE_URL="..."
   SUPABASE_ANON_KEY="..."
5. Загрузите обновлённый app.js на GitHub.

Важно: для продакшена стоит добавить CAPTCHA/антиспам и более строгую защиту от злоупотреблений. Publishable/anon key можно использовать на клиенте только вместе с корректными RLS-политиками.
